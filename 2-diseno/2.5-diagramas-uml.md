## Diagrama de Secuencia

### Secuencia 1: Registro de Denuncia por Ciudadano

```mermaid
sequenceDiagram
    actor Ciudadano
    participant WebApp as Aplicación Web
    participant AuthService as Servicio de Autenticación
    participant DenunciaService as Servicio de Denuncias
    participant EvidenciaService as Servicio de Evidencias
    participant NotificacionService as Servicio de Notificaciones
    participant Database as Base de Datos
    participant StorageService as Almacenamiento

    Ciudadano->>WebApp: Iniciar sesión (DNI + Fecha emisión)
    WebApp->>AuthService: validarCredenciales(dni, fecha_emision)
    AuthService->>Database: SELECT * FROM Ciudadano WHERE dni=?
    Database-->>AuthService: Datos del ciudadano
    AuthService->>AuthService: Verificar fecha_emision_dni
    
    alt Autenticación exitosa
        AuthService->>Database: INSERT INTO Sesion
        AuthService-->>WebApp: Token de sesión + datos usuario
        WebApp-->>Ciudadano: Dashboard ciudadano
        
        Note over Ciudadano,WebApp: RF-06 a RF-09: Registro de denuncia
        
        Ciudadano->>WebApp: Completar formulario de denuncia
        Ciudadano->>WebApp: Seleccionar categoría
        Ciudadano->>WebApp: Ingresar descripción
        Ciudadano->>WebApp: Seleccionar ubicación en mapa
        
        WebApp->>DenunciaService: validarDatosDenuncia(datos)
        
        alt Datos válidos
            Ciudadano->>WebApp: Adjuntar evidencias (máx 5)
            
            loop Por cada archivo
                WebApp->>EvidenciaService: validarArchivo(archivo)
                EvidenciaService->>EvidenciaService: Verificar tipo y tamaño
                EvidenciaService->>EvidenciaService: Escanear archivo (RS-19)
                
                alt Archivo válido
                    EvidenciaService->>EvidenciaService: Calcular hash SHA-256
                    EvidenciaService->>StorageService: Almacenar archivo encriptado
                    StorageService-->>EvidenciaService: Ruta de almacenamiento
                    EvidenciaService->>Database: INSERT INTO Evidencia
                else Archivo inválido
                    EvidenciaService-->>WebApp: Error de validación
                    WebApp-->>Ciudadano: Mostrar error específico
                end
            end
            
            Ciudadano->>WebApp: Confirmar registro
            WebApp->>DenunciaService: crearDenuncia(datos, evidencias)
            
            DenunciaService->>Database: BEGIN TRANSACTION
            DenunciaService->>Database: INSERT INTO Ubicacion
            Database-->>DenunciaService: id_ubicacion
            DenunciaService->>Database: INSERT INTO Denuncia (estado='Registrado')
            Database-->>DenunciaService: id_denuncia, codigo_denuncia
            DenunciaService->>Database: INSERT INTO Seguimiento (estado_nuevo='Registrado')
            DenunciaService->>Database: COMMIT TRANSACTION
            
            DenunciaService->>NotificacionService: enviarNotificacionRegistro(id_denuncia)
            NotificacionService->>Database: SELECT configuracion notificaciones usuario
            NotificacionService->>Database: SELECT plantilla 'REGISTRO_DENUNCIA'
            NotificacionService->>NotificacionService: Renderizar plantilla
            
            par Envío multi-canal (RF-01, RF-02)
                NotificacionService->>Email: Enviar email confirmación
                NotificacionService->>SMS: Enviar SMS con código seguimiento
            end
            
            NotificacionService->>Database: INSERT INTO Notificacion (estado='Enviado')
            
            DenunciaService-->>WebApp: Denuncia creada exitosamente
            WebApp-->>Ciudadano: Mostrar código de seguimiento
            
            Note over Ciudadano: RF-10: Ciudadano puede consultar estado
            
        else Datos inválidos
            DenunciaService-->>WebApp: Errores de validación
            WebApp-->>Ciudadano: Mostrar errores y corregir
        end
        
    else Autenticación fallida
        AuthService->>Database: INSERT INTO LogAuditoria (accion='LOGIN_FAILED')
        AuthService-->>WebApp: Credenciales inválidas
        WebApp-->>Ciudadano: Error de autenticación
    end
```

### Secuencia 2: Asignación y Procesamiento de Denuncia

```mermaid
sequenceDiagram
    actor PersonalMunicipal as Personal Municipal
    participant WebApp as Aplicación Web
    participant AuthService as Servicio de Autenticación
    participant DenunciaService as Servicio de Denuncias
    participant AsignacionService as Servicio de Asignaciones
    participant NotificacionService as Servicio de Notificaciones
    participant Database as Base de Datos

    PersonalMunicipal->>WebApp: Iniciar sesión
    WebApp->>AuthService: autenticar(usuario, password)
    AuthService->>Database: Validar credenciales
    Database-->>AuthService: Usuario válido + roles
    AuthService-->>WebApp: Token + permisos
    WebApp-->>PersonalMunicipal: Dashboard personal municipal
    
    Note over PersonalMunicipal: RF-13: Ver denuncias pendientes
    
    PersonalMunicipal->>WebApp: Ver denuncias asignadas/pendientes
    WebApp->>DenunciaService: obtenerDenunciasPorArea(id_area)
    DenunciaService->>Database: SELECT denuncias WHERE area=? AND estado IN (...)
    Database-->>DenunciaService: Lista de denuncias
    DenunciaService-->>WebApp: Denuncias con detalles
    WebApp-->>PersonalMunicipal: Mostrar lista priorizada
    
    PersonalMunicipal->>WebApp: Seleccionar denuncia
    WebApp->>DenunciaService: obtenerDetalleDenuncia(id_denuncia)
    DenunciaService->>Database: SELECT denuncia completa (JOIN evidencias, ubicación, etc)
    Database-->>DenunciaService: Detalles completos
    DenunciaService-->>PersonalMunicipal: Vista detallada
    
    Note over PersonalMunicipal: RF-14: Asignar denuncia
    
    alt Asignar a Personal
        PersonalMunicipal->>WebApp: Asignar a técnico específico
        WebApp->>AsignacionService: asignarDenuncia(id_denuncia, id_personal)
        AsignacionService->>Database: BEGIN TRANSACTION
        AsignacionService->>Database: INSERT INTO Asignacion
        AsignacionService->>Database: UPDATE Denuncia SET estado='Asignado'
        AsignacionService->>Database: INSERT INTO Seguimiento
        AsignacionService->>Database: COMMIT TRANSACTION
        
        AsignacionService->>NotificacionService: notificarAsignacion(id_personal, id_denuncia)
        NotificacionService->>Database: INSERT INTO Notificacion
        NotificacionService->>Email: Enviar notificación al técnico
        NotificacionService->>NotificacionService: Notificar al ciudadano (RF-19)
        
        AsignacionService-->>PersonalMunicipal: Asignación exitosa
    end
    
    Note over PersonalMunicipal: RF-15: Cambiar estado
    
    PersonalMunicipal->>WebApp: Cambiar estado a "En proceso"
    WebApp->>DenunciaService: cambiarEstado(id_denuncia, 'En_proceso')
    DenunciaService->>Database: BEGIN TRANSACTION
    DenunciaService->>Database: UPDATE Denuncia SET estado='En_proceso'
    DenunciaService->>Database: INSERT INTO Seguimiento (visible=true)
    DenunciaService->>Database: COMMIT TRANSACTION
    
    DenunciaService->>NotificacionService: notificarCambioEstado(id_denuncia)
    NotificacionService->>Database: Obtener configuración ciudadano
    NotificacionService->>Email: Enviar actualización
    NotificacionService-->>DenunciaService: Notificación enviada
    
    Note over PersonalMunicipal: RF-16: Adjuntar evidencia de resolución
    
    PersonalMunicipal->>WebApp: Subir foto de resolución
    WebApp->>DenunciaService: adjuntarEvidenciaResolucion(id_denuncia, archivo)
    DenunciaService->>Database: INSERT INTO Tramitacion (si no existe)
    DenunciaService->>Database: INSERT INTO Evidencia (tipo='resolucion')
    DenunciaService-->>PersonalMunicipal: Evidencia adjuntada
    
    Note over PersonalMunicipal: RF-20: Solicitar información adicional
    
    alt Requiere más información
        PersonalMunicipal->>WebApp: Solicitar información al ciudadano
        WebApp->>DenunciaService: enviarComunicacion(id_denuncia, mensaje)
        DenunciaService->>Database: INSERT INTO Comunicacion
        DenunciaService->>NotificacionService: notificar(id_ciudadano)
        NotificacionService->>Email: Enviar solicitud
        NotificacionService-->>PersonalMunicipal: Comunicación enviada
    end
    
    PersonalMunicipal->>WebApp: Registrar resolución
    WebApp->>DenunciaService: registrarResolucion(id_denuncia, datos)
    DenunciaService->>Database: BEGIN TRANSACTION
    DenunciaService->>Database: INSERT INTO Resolucion
    DenunciaService->>Database: UPDATE Denuncia SET estado='Resuelta'
    DenunciaService->>Database: INSERT INTO Seguimiento
    DenunciaService->>Database: COMMIT TRANSACTION
    
    DenunciaService->>NotificacionService: notificarResolucion(id_denuncia)
    NotificacionService->>Email: Enviar notificación de resolución
    NotificacionService-->>DenunciaService: Notificado
    
    DenunciaService-->>PersonalMunicipal: Resolución registrada exitosamente
```
